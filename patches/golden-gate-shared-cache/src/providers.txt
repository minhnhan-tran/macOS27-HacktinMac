# The artifact's retired-roots.txt must list every R line and may list C lines; any other root stops the build.
#   R  an image of Apple's x86_64 cache family that the image has on disk (dyld counts it as overridden)
#   C  a companion a provider loads, not in Apple's cache
#   N  a cache image (fnmatch pattern) that may stay on disk after the fold because no process loads it on this Mac;
#      the last gate skips it and lists it in the build record. Not a root: it is neither checked nor removed.
