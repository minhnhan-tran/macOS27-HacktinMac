Reduced security. m27 is a developer preview with reduced security: it is not
as secure as macOS on a supported Mac. System Integrity Protection is partly
off, Apple Mobile File Integrity (code-signature enforcement) is relaxed, and
the sealed system volume and Secure Boot are off. Pointer authentication (PAC)
is not enforced for the ARM code m27 translates. Install it only on a Mac that
holds nothing you need to protect.
